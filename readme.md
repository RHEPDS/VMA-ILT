# Virtualization Migration Assessment (VMA) Workshop\

## Overview
This workshop supports the technical motion of transitioning customers from VMware-based infrastructure to OpenShift-based infrastructure, focusing on the Red Hat Virtualization Migration Assessment (VMA).\

## Target Audience
- Technical Sales / PreSales
- Business Consultants
- Delivery Consultants

## Prerequisites
- OpenShift Knowledge (DO180)
- Basic understanding of OpenShift Virt
- VMware Knowledge
\
## Workshop Goals
- Gain confidence in identifying and convincing customers to commit to a [Virtualization Migration Assessment](https://portfoliohub.redhat.com/v3/serviceskit/openshift_virtualization_assessment).\
- Understand the existing customer environment.
- Assess migration risk.
- Run an Assessment as a Partner on the Customer Side.

## Proposed Final Outcomes
1. **Position** the business and technical value of the Virtualization Migration Assessment.
2. **Handle** technical or business competitive situations.
3. **Determine** when and where to engage an Ecosystem partner to support a VMA.
4. **Perform** an upfront Technical Discovery and Risk Assessment.
5. **Scope** a Proof of Concept for OpenShift Virtualization.
6. **Communicate** technical value during the delivery of the Virtualization Roadshow.
